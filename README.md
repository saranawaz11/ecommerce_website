# E-commerce Store (MERN Stack)

A full-stack **E-commerce application** built using the **MERN stack (MongoDB, Express, React, Node.js)**.  
This project includes user authentication, product management, shopping cart, checkout system, and admin dashboard.

## Features
- User authentication (login/signup with JWT)
- Product listing, search, filters, and categories
- Shopping cart and order management
- Image upload with Cloudinary/ImageKit
- Responsive UI built with React + Tailwind
- Secure API with role-based access (Admin/User)
- REST API with Express + MongoDB

## Tech Stack
- **Frontend:** React, Redux Toolkit, TailwindCSS  
- **Backend:** Node.js, Express.js, MongoDB  
- **Authentication:** JWT (JSON Web Tokens)  
- **Image Uploads:** ImageKit/Cloudinary  
- **State Management:** Redux Toolkit
